How to get a key (30 seconds)
  1. Open aistudio.google.com/apikey and sign in with your Google account.
  2. Click Create API key and copy it here.
  3. Recommended: click the key, add an HTTP referrer restriction for this site's address, and allow only the Generative Language API. Then the key is useless anywhere else if it ever leaks.
